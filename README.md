# FoodLoop AI — Rescue Food Before It Is Wasted

FoodLoop AI is a hackathon MVP that helps businesses list surplus food, ranks eligible recipient organizations with an explainable matching algorithm, records donation reservations, and tracks completed rescues.

## Features

- Overview dashboard with available and rescued food metrics
- Create surplus food listings with quantities, categories, storage notes, and pickup deadlines
- Explainable recipient matching based on category fit, capacity, pickup availability, distance, and urgency
- Reserve a donation for an organization
- Mark reserved donations as collected
- Impact report for completed donations and estimated meal portions
- CSV export of donation records
- Local JSON persistence for demo data

## Tech stack

- Python
- Streamlit
- Pandas
- Transparent weighted-ranking algorithm (heuristic, not a trained ML model)
- JSON local storage

## Run locally

Python 3.10+ recommended.

```bash
python -m venv .venv
# Windows PowerShell:
.\.venv\Scripts\Activate.ps1
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

The app should open in your browser at the local URL shown by Streamlit.

## Demo walkthrough (2–4 minutes)

1. Open Overview and show sample surplus listings.
2. Open Add donation and create a sample donation with a near pickup deadline.
3. Open AI matching and select the new listing.
4. Explain the ranked recipients and the reasons shown for each score.
5. Reserve the donation for the top eligible recipient.
6. Open Surplus listings and mark the reserved donation as collected.
7. Open Impact report and show the completed rescue metrics.
8. State clearly that seed data is synthetic and impact numbers are illustrative until real donations are completed.

## Data and safety notes

- Seed data and recipient profiles are fictional demo records.
- Matching scores are generated by a transparent heuristic. They are not predictions from a trained model.
- Estimated meal portions are based on a user-entered conversion and should not be represented as verified meals served.
- Do not list or redistribute food unless it is safe to donate under applicable local food-safety rules. Verify temperature control, allergens, packaging, pickup capacity, and organizational eligibility.
- Do not claim real environmental impact from hypothetical or merely listed donations.
